# Data Model: Decipherment Headroom

## Qualified Feasibility Decision

| Field                   | Rule                                                              |
| ----------------------- | ----------------------------------------------------------------- |
| `classification`        | `qualified-pass`                                                  |
| `profile`               | Unrecognized-literary stationary word substitution                |
| `observation`           | Semantic mapping progress beyond the tested mechanical attempt    |
| `recognitionDependency` | `false` for the accepted observation                              |
| `evidenceAvailability`  | Operator-observed; original judged outputs unavailable for replay |
| `authorizes`            | Minimum Gate C experiment only                                    |
| `fullHarnessAuthorized` | `false`                                                           |
| `deferredClaims`        | Explicit list of unsupported broader claims                       |

## Retained Literary Profile

The retained profile is the smallest stationary public/private/oracle instance geometry needed as the pre-switch segment of Gate C. Gate C owns all new switch, reveal, trajectory, and latency records.

## Deferred Replication

Deferred replication is a research backlog item, not an active gate state and not an input to Gate C.
