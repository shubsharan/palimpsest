# Contract: Puzzle Build v4

`puzzle-build.json` schema version 4 preserves the existing deterministic paired build and replaces `allocation.tier` with independent validity records.

## Evidence Tier

Contains tier identifier, specialist ownership and occurrence thresholds, solo-coverage metrics, stage and region balance, changed mass, and rejected evidence tiers.

Provider-backed work rejects `fallback`.

## Control Tier

Contains tier identifier, changed count, matched-control count, completeness, maximum and mean matching distance, and threshold bounds.

Calibration requires completeness and an explicit tier. Validation requires at least `balanced`.

## Identity

Paired build identity binds source digest, selected window, seed, allocation digest, oracle-design digest, manipulation digest, evidence tier, control tier, and both variant build identities.
